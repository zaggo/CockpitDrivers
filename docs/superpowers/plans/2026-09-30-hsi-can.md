# HSICAN Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert the HSI instrument from the AirManager-driven `HSIDriver` firmware to a CAN node `HSICAN`, including the DCU and X-Plane plugin halves of the chain.

**Architecture:** Three new CAN messages (`0x104` heading/OBS/bug/flags at 50 Hz, `0x105` CDI/GS deviation at 10 Hz, `0x341` knob deltas upstream) carried to and from X-Plane over three new serial message types. The board is a copy of `HSIDriver` with AirManager removed, CAN added, a reworked pin map (the MCP2515 needs the hardware SPI pins that servos currently occupy), EEPROM calibration, and non-blocking homing. Logic that can be tested without hardware moves into Arduino-free headers under `include/`.

**Tech Stack:** PlatformIO / Arduino (ATmega328P Nano, ATmega2560 Mega), MCP2515 via `coryjfowler/mcp_can`, MCP23017 via `blemasle/MCP23017`, `arduino-libraries/Servo`, Unity for native tests, X-Plane 12 SDK / CMake for the plugin.

**Spec:** `docs/superpowers/specs/2026-09-30-hsi-can-design.md`

## Global Constraints

- Branch: `feature/hsi-can`. No worktree. Do not merge to `main`.
- CAN bus: 500 kbit/s, MCP2515 on an 8 MHz crystal (`MCP_STDEXT, CAN_500KBPS, MCP_8MHZ`). All CAN payloads are 8 bytes, big-endian.
- Serial link DCU ↔ plugin: 115200 baud, framing `0xAA 0x55 TYPE LEN PAYLOAD...`, payload structs in **host** byte order (both ends little-endian).
- `0x341` is **onChange only**. It must never join `DCUReceiver::checkMaxAgeResync` and must never be resent on a timer — it carries deltas and a resend would apply the clicks twice.
- Arduino-free headers under a board's `include/` must not include `<Arduino.h>` and must compile under `platform = native`. Use `<stdint.h>`.
- No dynamic allocation in steady state on AVR; no `String` in `handleFrame`, `loop()` or the homing path. That includes anything a `loop()`-driven watch or poller calls.
- **Bench consoles print with `Serial.print`/`Serial.println`, never `DEBUGLOG_*`.** `DEBUGLOG_ENABLE` is `0` by default and the macros then expand to nothing, so a console built on them is mute in exactly the configuration people flash. Every existing bench console follows this: `DCU/src/BenchDebug.cpp` has 76 `Serial.print*` calls and zero `DEBUGLOG`, `AltimeterCAN/src/BenchDebug.cpp` has 56 and zero. `DEBUGLOG_*` remains correct in non-console code (`CAN.cpp`, `HSI.cpp`), where it is meant to compile away.
- New identifier names, used everywhere in `HSICAN`: `cdiServo`, `fromToServo`, `gs1Servo`, `gs2Servo`; axes `obs`, `compass`, `hdg`; pins `kObsEncoder*`, `kHdgEncoder*`.
- `HSIDriver` is not modified by any task in this plan.
- Every commit message ends with a `Co-Authored-By:` line naming the model that actually made the commit, in the form your own session's attribution guidance gives you. Do not copy another agent's model name — an attribution that names the wrong model is a false one.
- `pio` is reachable from implementer subagents but denied to the controlling session, so every build claim has to be made by whoever ran the build.

```cpp
  // 0x104: HSI heading / OBS / bug / flags (Gateway -> Instrument, 50Hz)
  // [0..1] compass heading uint16, degrees * 100, 0..35999
  //        (sim/cockpit2/gauges/indicators/heading_electric_deg_mag_pilot)
  // [2..3] OBS course    uint16, degrees * 100
  //        (sim/cockpit2/radios/actuators/hsi_obs_deg_mag_pilot)
  // [4..5] HDG bug       uint16, degrees * 100
  //        (sim/cockpit2/autopilot/heading_dial_deg_mag_pilot)
  // [6]    flags uint8: bit0 TO, bit1 FROM, bit2 GS valid, bits 3..7 reserved.
  //        TO/FROM come from sim/cockpit/radios/nav1_fromto (1 = TO, 2 = FROM);
  //        GS valid is sim/cockpit/radios/nav1_CDI, whose name is misleading —
  //        Laminar documents it as "Are we receiving an expected glide slope".
  // [7]    reserved
  hsiHeading = 0x104,

  // 0x105: HSI deviation needles (Gateway -> Instrument, 10Hz)
  // [0..1] CDI deviation int16, dots * 1000 (sim/cockpit/radios/nav1_hdef_dot)
  // [2..3] GS  deviation int16, dots * 1000 (sim/cockpit/radios/nav1_vdef_dot)
  // [4..7] reserved
  // int16 at dots*1000 spans +-32.7 dots; nav1_hdef_dot reaches +-2.5. The
  // dots -> servo degree conversion happens on the board and is calibratable.
  hsiNav = 0x105,
```

- [ ] **Step 3: Add the cluster-input id with its resend exception**

```cpp
// Message payload for Plugin > DCU, repacked into CAN 0x104.
#if defined(_MSC_VER)
    #pragma pack(push, 1)
    struct HsiHeadingMessage {
        float   headingDegMag;  // heading_electric_deg_mag_pilot
        float   obsDeg;         // hsi_obs_deg_mag_pilot
        float   hdgBugDeg;      // heading_dial_deg_mag_pilot
        uint8_t flags;          // bit0 TO, bit1 FROM, bit2 GS valid
    };
    struct HsiNavMessage {
        float cdiDots;          // nav1_hdef_dot
        float gsDots;           // nav1_vdef_dot
    };
    struct HsiInputToDcuMessage {
        uint8_t control;        // 0 = OBS, 1 = HDG
        uint8_t action;         // 0 = delta, 1 = push
        int16_t delta;          // encoder clicks, signed
        uint8_t pushState;      // 0/1
    };
    #pragma pack(pop)
#else
    struct __attribute__((packed)) HsiHeadingMessage {
        float   headingDegMag;
        float   obsDeg;
        float   hdgBugDeg;
        uint8_t flags;
    };
    struct __attribute__((packed)) HsiNavMessage {
        float cdiDots;
        float gsDots;
    };
    struct __attribute__((packed)) HsiInputToDcuMessage {
        uint8_t control;
        uint8_t action;
        int16_t delta;
        uint8_t pushState;
    };
#endif
```

- [ ] **Step 6: Pin the struct sizes with static assertions**

The DCU parses these frames by length, so a packing attribute that silently fails to apply would be a wire-protocol bug. Rather than checking once with a throwaway program, assert it permanently — every consumer then re-checks on every build.

At the end of `SerialMessageId.h`, after the struct definitions and before the closing `#endif`:

```cpp
// The DCU dispatches on payload length, so these sizes are the wire contract.
// Without the packing attribute above, HsiHeadingMessage would be padded to 16
// and every frame would be rejected as malformed.
static_assert(sizeof(HsiHeadingMessage) == 13, "HsiHeadingMessage must be 13 bytes on the wire");
static_assert(sizeof(HsiNavMessage) == 8, "HsiNavMessage must be 8 bytes on the wire");
static_assert(sizeof(HsiInputToDcuMessage) == 5, "HsiInputToDcuMessage must be 5 bytes on the wire");
```

- [ ] **Step 3: Write the header**

Create `shared/CANBase/include/HsiWire.h`:

```cpp
#ifndef HSIWIRE_H
#define HSIWIRE_H

#include <stdint.h>
#include <math.h>

// Wire helpers for CAN 0x104, shared by the DCU and DCUProviderPlugin - both
// resolve this directory already. Deliberately Arduino-free: the plugin is
// desktop C++, and the native Unity tests in DCU/test/test_hsi_flags exercise
// these directly (pio test -e native).

// Composes the flags byte of CAN 0x104 byte 6.
//   fromTo            sim/cockpit/radios/nav1_fromto: 0 none, 1 TO, 2 FROM
//   glideslopeValid   sim/cockpit/radios/nav1_CDI, nonzero when NAV1 is
//                     receiving an expected glide slope
// Anything other than 1 or 2 in fromTo means no usable bearing, which is the
// same as "no nav" and leaves both direction bits clear.
inline uint8_t hsiFlagsByte(int fromTo, int glideslopeValid)
{
    uint8_t flags = 0;
    if (fromTo == 1)
    {
        flags |= 0x01;
    }
    else if (fromTo == 2)
    {
        flags |= 0x02;
    }
    if (glideslopeValid != 0)
    {
        flags |= 0x04;
    }
    return flags;
}

// Folds a heading into 0..35999 hundredths of a degree. X-Plane hands out
// slightly negative values and values past 360 depending on its internal
// state; an unwrapped negative cast to uint16 would send an axis on a full
// spurious turn.
inline uint16_t hsiWrapDeg100(float degrees)
{
    float wrapped = fmodf(degrees, 360.0f);
    if (wrapped < 0.0f)
    {
        wrapped += 360.0f;
    }
    uint32_t deg100 = (uint32_t)(wrapped * 100.0f + 0.5f);
    if (deg100 > 35999)
    {
        deg100 = 0;
    }
    return (uint16_t)deg100;
}

#endif // HSIWIRE_H
```

```cpp
void DCUReceiver::sendHsiHeading()
{
  byte data[8] = {0};

  // [0..1] heading, [2..3] OBS, [4..5] HDG bug, all degrees * 100.
  // [6] flags, [7] reserved.
  packBE16(data + 0, hsiHeadingDeg100);
  packBE16(data + 2, hsiObsDeg100);
  packBE16(data + 4, hsiHdgBugDeg100);
  data[6] = hsiFlags;

  canBus->sendMessage(CanMessageId::hsiHeading, 8, data);

  hsiHeadingMeta.lastSendTimestamp = millis();
}

void DCUReceiver::sendHsiNav()
{
  byte data[8] = {0};

  // [0..1] CDI deviation, [2..3] GS deviation, both dots * 1000, signed.
  packBE16(data + 0, static_cast<uint16_t>(hsiCdiDots1000));
  packBE16(data + 2, static_cast<uint16_t>(hsiGsDots1000));

  canBus->sendMessage(CanMessageId::hsiNav, 8, data);

  hsiNavMeta.lastSendTimestamp = millis();
}
```

```cpp
  case MessageType::SerialMessageHsiHeading:
  {
    if (len != sizeof(HsiHeadingMessage))
      return;

    HsiHeadingMessage msg;
    memcpy(&msg, payload, sizeof(msg));

    const uint16_t heading100 = hsiWrapDeg100(msg.headingDegMag);
    const uint16_t obs100 = hsiWrapDeg100(msg.obsDeg);
    const uint16_t bug100 = hsiWrapDeg100(msg.hdgBugDeg);

    if (heading100 != hsiHeadingDeg100 || obs100 != hsiObsDeg100 ||
        bug100 != hsiHdgBugDeg100 || msg.flags != hsiFlags)
    {
      hsiHeadingDeg100 = heading100;
      hsiObsDeg100 = obs100;
      hsiHdgBugDeg100 = bug100;
      hsiFlags = msg.flags;
      sendHsiHeading();
    }
    break;
  }

  case MessageType::SerialMessageHsiNav:
  {
    if (len != sizeof(HsiNavMessage))
      return;

    HsiNavMessage msg;
    memcpy(&msg, payload, sizeof(msg));
```

```cpp
void CAN::updateHsiInput(uint8_t len, const uint8_t *data)
{
    // CAN 0x341: [0] control, [1] action, [2..3] delta int16 BE, [4] pushState.
    // The serial side carries the same fields in host order.
    //
    // No cache and no resend: these are deltas. Replaying one would turn the
    // knob twice, which is why this message stays out of checkMaxAgeResync.
    if (len < 5)
        return;

    HsiInputToDcuMessage msg;
    msg.control = data[0];
    msg.action = data[1];
    msg.delta = static_cast<int16_t>(unpackBE16(data + 2));
    msg.pushState = data[4];

    // Every other decoded instrument input logs on arrival; this whole chain is
    // debugged over the serial log at the bench.
    DEBUGLOG_PRINTLN(String(F("Received HSI input control: ")) + String(msg.control) +
                     String(F(" action: ")) + String(msg.action) +
                     String(F(" delta: ")) + String(msg.delta) +
                     String(F(" push: ")) + String(msg.pushState));

#if BENCHDEBUG
    // No DCUSender in bench builds - hand the event to BenchDebug's watch
    // instead of dropping it below.
    hsiInputSample = msg;
    hsiInputSampleValid = true;
#endif

    if (dcuSender != nullptr)
    {
        dcuSender->sendFrame(MessageType::SerialMessageHsiInput,
                             sizeof(msg),
                             reinterpret_cast<const uint8_t *>(&msg));
    }
}
```

```cpp
#ifndef HSIGEOMETRY_H
#define HSIGEOMETRY_H

#include <stdint.h>

// Axis geometry and homing maths for HSICAN. Deliberately Arduino-free so both
// can be exercised by the native Unity tests in test/test_geometry
// (pio test -e native).

// --- axis targets -----------------------------------------------------------

// Motor angles for the three stepper axes, in hundredths of a degree, 0..35999.
struct AxisTargets
{
    uint16_t compassAxis100;
    uint16_t obsAxis100;
    uint16_t hdgAxis100;
};

// The course pointer and the heading bug sit on the rotating compass card, so
// their axes carry the pointer's offset from the current heading rather than an
// absolute angle. Only the card itself is mirrored.
//
// The old AirManager LUA pre-mirrored all three values before sending them
// (-h, 360-o, 360-b) and the firmware then differenced them. Substituting those
// in, the mirroring cancels on the two pointers and only the card keeps it:
//
//     compass = (-h)    mod 360
//     obs     = (o - h) mod 360
//     hdg     = (b - h) mod 360
//
// Unrelated to CheapStepper's `inversed` flag, which reverses the coil sequence
// rather than the target angle. Both are active on the rig.
inline AxisTargets axisTargets(uint16_t heading100, uint16_t obs100, uint16_t hdgBug100)
{
    const int32_t full = 36000;
    const int32_t h = (int32_t)heading100;

    AxisTargets t;
    t.compassAxis100 = (uint16_t)(((full - h) % full + full) % full);
    t.obsAxis100 = (uint16_t)((((int32_t)obs100 - h) % full + full) % full);
    t.hdgAxis100 = (uint16_t)((((int32_t)hdgBug100 - h) % full + full) % full);
    return t;
}

// --- homing window centre ---------------------------------------------------

// Half the hall window, measured from its far edge back to its near edge.
//
// The two edges are captured in different homing phases with a resetPosition()
// between them, so the difference is naturally unsigned - and that is the trap.
// If `zeroEnd` has wrapped below `zeroStart` the difference comes back as
// almost a whole turn and halves into a silent 180 degree mis-home that still
// reports success. WhiskeyCompassCAN was bitten by exactly this, twice.
//
// A hall window spans a few degrees, so anything wider than an eighth of a turn
// is a misread rather than a window. Returns false and leaves *centreSteps
// untouched in that case; the caller turns that into a homing timeout.
inline bool homingWindowCentre(uint32_t zeroEnd, uint32_t zeroStart,
                               uint32_t totalSteps, int32_t *centreSteps)
{
    if (totalSteps == 0 || centreSteps == 0)
    {
        return false;
    }

    const uint32_t span = (zeroEnd + totalSteps - (zeroStart % totalSteps)) % totalSteps;
    if (span > totalSteps / 8)
    {
        return false;
    }

    *centreSteps = (int32_t)(span / 2);
    return true;
}

#endif // HSIGEOMETRY_H
```

```cpp
#ifndef BACKLASH_H
#define BACKLASH_H

#include <stdint.h>

// Gear backlash bookkeeping for HSICAN's three geared stepper axes.
// Deliberately Arduino-free so the partial-reversal case - the one that is easy
// to get wrong and invisible anywhere but the rig - is covered by the native
// Unity tests in test/test_backlash (pio test -e native).
//
// The model: `unused` counts slack steps still to be crossed before the output
// moves again. While it is nonzero the motor turns and the output does not,
// which is what makes the tracked position an *output* position rather than a
// motor position - and that in turn is what makes shortest-path routing and the
// homing captures correct.

// Slack still to cross after a direction change. Whatever was already travelled
// in the old direction (total - unused) is exactly what must be travelled back.
inline uint32_t backlashOnReversal(uint32_t unused, uint32_t total)
{
    if (unused >= total)
    {
        return 0;
    }
    return total - unused;
}

// Accounts one motor step. Returns true if the step was swallowed by the slack,
// false if it should advance the tracked output position.
inline bool consumeBacklashStep(uint32_t *unused)
{
    if (unused == 0 || *unused == 0)
    {
        return false;
    }
    (*unused)--;
    return true;
}

// Whether a computed move is worth issuing.
//
// 0x104 arrives at 50 Hz carrying hundredths of a degree, and at 11.38 steps per
// degree the integer step target jitters by +-1 continuously. Every one of those
// flips would append a whole slack crossing - up to 75 steps on the heading bug -
// so a pointer that should be standing still would instead be driven back and
// forth through the gear play: audible, wearing, and never settling.
//
// A reversal therefore has to clear a larger threshold than a continuation,
// because only a reversal pays for the slack. A reversalDeadband of 0 turns the
// behaviour off.
inline bool moveIsWorthMaking(int32_t steps, bool lastDirectionClockwise,
                              uint32_t moveDeadband, uint32_t reversalDeadband)
{
    if (steps == 0)
    {
        return false;
    }

    const uint32_t magnitude = (uint32_t)(steps < 0 ? -steps : steps);
    const bool clockwise = steps > 0;
    const uint32_t limit = (clockwise != lastDirectionClockwise) ? reversalDeadband
                                                                 : moveDeadband;
    return magnitude >= limit;
}

#endif // BACKLASH_H
```

```cpp
#ifndef HSICALIBRATION_H
#define HSICALIBRATION_H

#include <stdint.h>

// Calibration maths for HSICAN: needle zero offsets, servo linkage travel and
// the deviation-dot conversion. Deliberately Arduino-free so all of it can be
// exercised by the native Unity tests in test/test_calibration
// (pio test -e native).

// --- needle zero adjust -----------------------------------------------------

// Folds a degree value into -180..179 so repeated calibration passes cannot
// accumulate whole turns.
inline int16_t normalizeZeroAdjust(int32_t degrees)
{
    int32_t wrapped = degrees % 360;
    if (wrapped < -180)
    {
        wrapped += 360;
    }
    else if (wrapped > 179)
    {
        wrapped -= 360;
    }
    return (int16_t)wrapped;
}

// After homing, an axis sits at position 0 with the stored offset already
// applied. Jogging it by `jogDegrees` onto the true mark therefore means the new
// offset is the sum of the two - replacing instead of adding throws away every
// previous pass and makes the needle wander a little further each time.
inline int16_t accumulateZeroAdjust(int16_t stored, int32_t jogDegrees)
{
    return normalizeZeroAdjust((int32_t)stored + jogDegrees);
}

// The stepper reports its position normalised into 0..totalSteps-1, so a small
// counter-clockwise jog comes back as nearly a full turn. Fold it back onto the
// short way round before converting to degrees.
inline int32_t jogDegreesFromPosition(uint32_t position, uint32_t totalSteps)
{
    if (totalSteps == 0)
    {
        return 0;
    }

    const int32_t total = (int32_t)totalSteps;
    int32_t steps = (int32_t)position;
    if (steps > total / 2)
    {
        steps -= total;
    }
    return steps * 360 / total;
}

// --- servo travel -----------------------------------------------------------

// Clamp to the mechanical travel, scale by the linkage ratio, then add the
// mounting offset. That order is load-bearing: clamping after scaling would let
// a ratio of 2 drive twice the intended travel.
//
// ratio1000 and adjustDeg100 are the EEPROM-stored fixed-point forms of the
// per-servo linkage ratio and mounting offset.
inline double servoTargetDegree(double input, double minDeg, double maxDeg,
                                int16_t ratio1000, int16_t adjustDeg100)
{
    double clamped = input;
    if (clamped < minDeg)
    {
        clamped = minDeg;
    }
    if (clamped > maxDeg)
    {
        clamped = maxDeg;
    }
    return clamped * ((double)ratio1000 / 1000.0) + ((double)adjustDeg100 / 100.0);
}

// --- deviation dots ---------------------------------------------------------

// CAN 0x105 carries deviation as dots * 1000. degPerDot100 is the EEPROM-stored
// conversion; the AirManager LUA used a flat factor of 10 degrees per dot for
// both needles, which is the shipped default.
inline double dotsToServoDegree(int16_t dots1000, int16_t degPerDot100)
{
    return ((double)dots1000 / 1000.0) * ((double)degPerDot100 / 100.0);
}

#endif // HSICALIBRATION_H
```

```cpp
void CAN::loop()
{
    InstrumentCAN::loop();

    if (!hsi->homingFailed())
    {
        homingFailedAtMs = 0;
        return;

    const uint32_t now = millis();
    if (homingFailedAtMs == 0)
    {
        homingFailedAtMs = now;

        hsi->beginHoming();
    }
```

```cpp
bool HSI::takeObsDelta(int16_t *delta)
{
    noInterrupts();
    const int16_t now = currentObsEncoder;
    interrupts();

    const int16_t diff = now - lastSentObsEncoder;
    if (diff == 0)
    {
        return false;
    }
    lastSentObsEncoder = now;
    *delta = diff;
    return true;
}
```

```cpp
uint32_t HSI::measureBacklashSteps(HSIAxis axis)
{
    // Creep one way until the hall sensor switches, then reverse and count how
    // many steps pass before it switches back. Those are the steps the gear
    // train swallows. Call only with stepsBacklash already set to 0, otherwise
    // the compensation hides the very thing being measured.
    const uint32_t limit = axes[axis]->getTotalSteps() / 4;

    axes[axis]->setRpm(kRpmLimits[axis][minRpm]);

    readHalls();
    fetchZeroedState(axis);
    const bool startState = zeroedState[axis];

    // Phase 1: drive forward onto the sensor edge.
    axes[axis]->newMove(true, limit);
    while (axes[axis]->getStepsLeft() != 0)
    {
        axes[axis]->run();
        sendMotorData();
        readHalls();
        fetchZeroedState(axis);
        if (zeroedState[axis] != startState)
        {
            break;
        }
    }
    axes[axis]->stop();

    if (zeroedState[axis] == startState)
    {
        DEBUGLOG_PRINTLN(F("HSI: no edge found, aborting"));
        axes[axis]->setRpm(kRpmLimits[axis][maxRpm]);
        return 0;
    }

    const bool edgeState = zeroedState[axis];

    // Phase 2: reverse and count until the edge comes back. The slack is
    // crossed before the output moves, so those steps are the measurement.
    uint32_t steps = 0;
    axes[axis]->newMove(false, limit);
    while (axes[axis]->getStepsLeft() != 0)
    {
        axes[axis]->run();
        sendMotorData();
        steps++;
        readHalls();
        fetchZeroedState(axis);
        if (zeroedState[axis] != edgeState)
        {
            break;
        }
    }
    axes[axis]->stop();

    // Put the speed back: leaving the axis at minRpm would make every later
    // move on it crawl until the next homing pass.
    axes[axis]->setRpm(kRpmLimits[axis][maxRpm]);

    return steps;
}
```
